# ZSD001_CLC — Paket Kuralları

## Naming (zorunlu prefix'ler)

| Obje Tipi | Prefix | Regex |
|---|---|---|
| Program | `ZSD001_P_*` | `^ZSD001_P_[A-Z0-9_]+$` |
| Include | `ZSD001_I_*` | `^ZSD001_I_[A-Z0-9_]+$` |
| Class | `ZSD001_CL_*` veya `ZCL_ZSD001_*` | `^(ZSD001_CL_|ZCL_ZSD001_)[A-Z0-9_]+$` |
| Function Group | `ZSD001_FG_*` | `^ZSD001_FG_[A-Z0-9_]+$` |
| Function Module | `ZSD001_FM_*` | `^ZSD001_FM_[A-Z0-9_]+$` |
| CDS Root View | `ZSD001_C_*` | `^ZSD001_C_[A-Z0-9_]+$` |
| CDS Interface View | `ZSD001_I_*` | `^ZSD001_I_[A-Z0-9_]+$` |
| DDL Source | `ZSD001_DDL_*` | `^ZSD001_DDL_[A-Z0-9_]+$` |
| Data Element | `ZSD001_DE_*` veya `ZSD001_DTEL_*` | `^ZSD001_(DE\|DTEL)_[A-Z0-9_]+$` |
| Domain | `ZSD001_DOM_*` | `^ZSD001_DOM_[A-Z0-9_]+$` |
| Structure | `ZSD001_S_*` | `^ZSD001_S_[A-Z0-9_]+$` |
| Table | `ZSD001_T_*` | `^ZSD001_T_[A-Z0-9_]+$` |
| Table Type | `ZSD001_TT_*` | `^ZSD001_TT_[A-Z0-9_]+$` |
| Lock Object | `EZSD001_*` veya `EZ_ZSD001_*` | (lock obj prefix `E` ile başlar) |
| Message Class | `ZSD001` | tek tablo, paket adıyla aynı |

> Validator: `scripts/validators/check_package_naming.py` bu regex'leri okuyup `cds/`, `classes/`, `programs/`, vb. altındaki dosya adlarını doğrular.
